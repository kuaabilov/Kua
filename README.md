## Быстрый запуск

1. Скачай ZIP по кнопке выше и распакуй его.
2. Перейди в `Kua-main/aitu-attendance`.
3. В Windows открой **`start.bat`** двойным кликом. На других системах открой **`index.html`** в браузере.

Подробности, возможности и пример расчёта — в [README калькулятора](aitu-attendance/README.md).
