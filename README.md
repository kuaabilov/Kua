## Как пользоваться

Вкладка **Обзор** показывает среднюю посещаемость, GPA, открытые дедлайны и пары на сегодня.

- **Attendance** — прежняя таблица и быстрые калькуляторы пропусков. Инструкция ниже.
- **GPA** — средневзвешенная оценка: сумма (кредиты × оценка GPA) / сумма кредитов. Вводятся итоговые баллы от 0 до 4; это не официальный транскрипт.
- **Расписание** — еженедельные пары с временем и кабинетом или заметкой.
- **Дедлайны** — задания, даты, редактирование и отметки о выполнении.
- **Импорт Moodle** — вставка скопированной таблицы Attendance и импорт файла календаря `.ics` с предпросмотром.

### Импорт из Moodle AITU

Используемый LMS: [lms.astanait.edu.kz](https://lms.astanait.edu.kz/).

Для attendance скопируй строки таблицы Moodle вместе с названием, Taken sessions и Points over taken sessions. Совпадающие названия обновляются, число занятий за триместр сохраняется. Новым предметам нужно указать план триместра вручную. Импорт переключает таблицу в режим баллов. Лимит — 30 предметов.

Для календаря открой в Moodle **Календарь → Экспорт календаря**, выбери период и скачай `.ics`. События добавляются в дедлайны; совпадающие UID обновляются. Это разовый импорт, а не фоновая подписка. Повторяющиеся события, отменённые события и неподдерживаемые даты пропускаются с указанием количества. События без времени получают срок 23:59; даты с часовым поясом переводятся во время устройства. Максимум файла — 2 МБ; до 1000 записей в каждом разделе кабинета.

Автоматическая синхронизация через API **не подключена**. Для неё Moodle должен предоставлять разрешённые веб-сервисы и доступ к данным. Наличие входа OpenID Connect не означает разрешение стороннему сайту читать журнал. Пароли и токены приложение не запрашивает.

Документация: [Moodle Web services](https://docs.moodle.org/501/en/Setting_up_a_web_service), [Calendar export](https://docs.moodle.org/501/en/Calendar_export).

### Attendance

1. Добавь предмет.
2. Перенеси **Taken sessions** — число уже проведённых занятий.
3. В режиме **«По баллам»** введи обе цифры из **Points over taken sessions**, например `36 / 40`. Или выбери **«По проценту»**.
4. Введи общее число занятий по предмету за триместр.
5. Укажи порог из правил курса — таблица покажет эквивалент пропусков и оставшийся лимит.

## Что означает результат

`20 занятий, 36 / 40 баллов` → `90%` → эквивалент `2` полностью пропущенных занятий.
При `30` занятиях за триместр и пороге `70%` можно пропустить ещё `7`, если за остальные будущие занятия начислят полный балл.

**Эквивалент пропусков не всегда равен числу отсутствий.** Частичные отметки могут дать тот же недобор баллов. Расчёт предполагает одинаковый вес всех занятий.

Округлённый процент даёт оценку. Вводи его с той же точностью, что в журнале: `90.0` и `90` различаются. Возможный остаток показан диапазоном; нижняя граница — более осторожная оценка.

## Возможности

- Несколько предметов в одной таблице.
- Ввод баллов или процента attendance.
- Отдельный расчёт для каждой дисциплины.
- Русский, казахский и английский интерфейс.
- Автосохранение на текущем устройстве и отмена удаления строки.
- Адаптивное отображение на телефоне.

Введённые значения хранятся в localStorage этого браузера. Они не отправляются в репозиторий или на сервер. Кнопка «Добавить пример» использует демонстрационные значения.

## Исходники

- `calculator.js` — расчёты и валидация.
- `app.js` — интерфейс, языки и локальное сохранение.

GitHub Pages публикуется из `main / (root)`. Локально достаточно открыть `index.html` вместе с остальными файлами.

Неофициальный инструмент. Порог 70% редактируется и не является гарантией допуска к экзамену.
