# Калькулятор пропусков AITU

Статический сайт для расчёта количества допустимых пропусков по одному предмету.

## Запуск

Скачайте папку целиком и откройте `index.html` в браузере. Установка зависимостей и сборка не нужны. Для загрузки шрифтов Google Fonts требуется интернет; без него используются системные шрифты.

## Параметры

- Занятий в неделю и недель в триместре.
- Уже пропущенные занятия.
- Минимальная посещаемость (по умолчанию 70%, настраивается).

Лимит: `floor(занятий_в_неделю × недель × (100 − порог) / 100)`.

Неофициальный калькулятор. Порог необходимо сверять с правилами конкретной дисциплины. Результат сам по себе не подтверждает допуск к экзамену.

## Файлы

- `index.html` — интерфейс.
- `style.css` — оформление и адаптация под мобильные экраны.
- `app.js` — расчёты в браузере.
