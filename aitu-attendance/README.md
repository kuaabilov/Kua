## Запустить на своём ПК

1. Нажми **«Скачать для ПК»** выше — скачается ZIP всего репозитория.
2. **Распакуй архив** через «Извлечь всё».
3. Открой папку `Kua-main → aitu-attendance`.
4. В Windows дважды нажми **`start.bat`** — сайт откроется в браузере по умолчанию.

**macOS / Linux или запуск вручную:** открой `index.html` в любом современном браузере.

> Открывай файлы после распаковки. Сохрани `index.html`, `style.css` и `app.js` в одной папке. GitHub показывает исходники; кнопка выше скачивает проект, а запуск выполняется на твоём компьютере.

## Что умеет калькулятор

| Возможность | Для чего |
| :--- | :--- |
| Нагрузка по предмету | Укажи пары в неделю и количество учебных недель |
| Учёт пропусков | Введи, сколько занятий уже пропущено |
| Настраиваемый порог | Выбери минимальную посещаемость своего курса |
| Остаток лимита | Сразу увидишь, сколько пар ещё можно пропустить |
| Статус и индикатор | Покажут, использован ли лимит или уже превышен |
| Адаптивный интерфейс | Страница подстраивается под размер экрана |

## Пример за 10 секунд

| Ввод | Значение |
| :--- | ---: |
| Пар в неделю | 3 |
| Недель | 10 |
| Минимальная посещаемость | 70% |
| Уже пропущено | 2 |

**Результат:** 30 занятий за триместр → максимум 9 пропусков → **осталось 7**.

```text
Всего занятий = пары в неделю × учебные недели
Лимит = округлить вниз(всего занятий × (100 − порог) / 100)
Остаток = максимум(0, лимит − уже пропущено)
```

Расчёт делается **отдельно для каждого предмета**. Порог 70% установлен по умолчанию и редактируется. Сверяй его с правилами своей дисциплины: калькулятор не подтверждает допуск к экзамену.

## Вопросы

<details>
<summary><b>Нужно устанавливать Python, Node.js или программу?</b></summary>

Нет. Достаточно распаковать архив и открыть сайт в браузере.

</details>

<details>
<summary><b>Работает без интернета?</b></summary>

Да, расчёты выполняются локально. Google Fonts загружаются из интернета; без подключения страница использует системные шрифты.

</details>

<details>
<summary><b>Где сохраняются мои данные?</b></summary>

Введённые значения используются только на открытой странице. Сайт не отправляет их на сервер и не сохраняет после перезагрузки.

</details>
