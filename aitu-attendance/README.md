## Как пользоваться

1. Укажи количество пар в неделю и недель в триместре.
2. Введи число уже пропущенных занятий.
3. Задай минимальную посещаемость по правилам своего предмета.
4. Посмотри оставшийся лимит пропусков.

## Пример

**3 пары × 10 недель = 30 занятий.** При минимальной посещаемости 70% лимит составляет 9 пропусков. Если уже пропущено 2 занятия, остаётся **7**.

Расчёт выполняется отдельно для каждого предмета. Порог 70% — редактируемое значение по умолчанию; сверь его с правилами курса. Это неофициальный калькулятор, а не подтверждение допуска к экзамену.
